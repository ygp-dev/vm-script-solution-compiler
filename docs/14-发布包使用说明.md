# VM Script Solution Compiler 使用说明

## 安装

运行 `VM-Script-Solution-Compiler-Setup-1.0.8-x64.exe`，按向导选择安装目录。默认目录为 `%LOCALAPPDATA%\VMSC`。

如果需要从 VisionMaster 4.4 Lite 中启动本产品，请在组件页面勾选“安装到 VisionMaster 4.4 Lite（添加 AI 助手按钮）”。安装时关闭 VisionMaster，并在系统提示时允许修改其安装目录。完成后重新启动 VisionMaster，点击右上角的“VM Script Compiler AI 助手”按钮。

不勾选时，桌面程序仍可从桌面或开始菜单独立启动。再次运行安装程序并取消勾选会移除之前添加到 VisionMaster 的按钮。卸载本产品时也会移除该按钮。

## 入口

- 桌面 Agent：开始菜单“VM Script Solution Compiler”，或安装目录下的 `Desktop\vm-script-compiler-desktop.exe`。
- CLI：开始菜单“VM Script Solution Compiler CLI”，或安装目录下的 `Cli\VmScriptCompiler.Cli.exe`。
- MCP：安装目录下的 `Mcp\vm-script-compiler-mcp.exe`。

需要 VisionMaster 4.4 才能创建、修改和验证 SOL 方案。请先在 VisionMaster 中备份待修改的方案文件。
