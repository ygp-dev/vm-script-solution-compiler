# 发布包使用说明

运行以下命令生成正式 Windows x64 发布：

```powershell
scripts\publish.ps1
```

生成包含 Desktop、CLI、MCP 的 NSIS 当前用户安装包：

```powershell
scripts\build-installer.ps1 -SkipPublish
```

默认输出到 `artifacts\release\v1.0.0`，并同时生成 SHA-256 校验文件和 `release-manifest.json`。安装包默认安装到 `%LOCALAPPDATA%\VMSC`，无需管理员权限；较短的目录用于兼容 Desktop 完整 Node.js 运行时依赖的 Windows 路径长度。

静默安装与卸载：

```powershell
VM-Script-Solution-Compiler-Setup-1.0.0-x64.exe /S
"%LOCALAPPDATA%\VMSC\Uninstall.exe" /S
```

创建 GitHub Release：

```powershell
scripts\publish-github-release.ps1 -Version 1.0.0 -SkipBuild
```

## 发布产品

- `dist\Desktop\vm-script-compiler-desktop.exe`：普通用户主产品，也是完整 VM 领域 Agent 桌面版；
- `dist\Cli\VmScriptCompiler.Cli.exe`：确定性 Requirement IR 命令行；
- `dist\Mcp\vm-script-compiler-mcp.exe`：供 Codex 等外部客户端调用的确定性 stdio MCP。

旧 `VmScriptCompiler.Agent` 一次性适配器不进入正式发布包。

Desktop 目录包含：

- `runtime\node.exe`：固定 Node 22.19.0；
- `agent\`：Pi 0.82.1 VM 领域 Agent、资源、锁文件和生产依赖；
- `worker\vm-script-domain-worker.exe`：自包含确定性编译 Worker；
- `resources`、`schemas`、`tools`：VM 4.4 编译资源、Requirement schema 和解析器。

因此 Desktop 整个目录可复制到源码目录以外运行，目标机器无需另装 Node 或 .NET。不要只复制单个 EXE。目标机器仍需安装 VisionMaster 4.4。

正式发布会在 `npm audit` 通过后裁剪未开放的 Mistral Provider SDK，以及只供开发调试的 TypeScript 声明和 Source Map。产品支持的 OpenAI Responses、OpenAI-compatible、Pi 领域 Agent及其运行依赖均保留，并由独立发布烟测验证。

## 安全与运行边界

- 发布包不包含 `.sol` 模板；
- AI 不直接修改 SOL；
- Patch 不覆盖输入文件；
- API Key 由 Desktop 使用 Windows 当前用户 DPAPI 加密，不写入发布包、会话或报告；
- 外部 DLL 的部署脚本需要用户检查后显式执行；
- 自动验证只到 `offline-validated`，VM 打开、编译、运行、保存和重开由用户确认。

## 同步与完整性

`dist\release-manifest.json` 记录三个产品入口哈希，以及 Desktop Agent 主程序、Node、Domain Worker 和共享 Core 的关键完整性哈希。`componentSynchronization.desktopWorkerAndMcp` 必须为 `true`。

MCP 或 Desktop 已经启动时不会热更新内存中的代码。发布完成后关闭并重新打开 Desktop；MCP 由客户端重新连接后加载新版本。
