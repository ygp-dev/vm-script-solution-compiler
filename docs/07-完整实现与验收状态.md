## 安全门禁

- 输入 SOL 永不原地覆盖，并在自动测试中校验 SHA-256 不变。
- Create 引用不存在的业务模块返回 `EXTERNAL_MODULE_NOT_AVAILABLE`。
- IO 默认值和声明类型不一致返回 `IO_TYPE_MISMATCH`。
- 未确认且未提供 `path + referenceType: 4` 的程序集引用返回 `REFERENCE_TYPE_UNCONFIRMED`；显式外部 DLL 会执行 Identity、版本、CLR、架构、递归依赖和哈希校验，并输出部署包。
- AI/Agent 只输出 Requirement IR 和脚本源码，不直接编辑 SOL。
- 项目与发布资源不包含 `.sol` 模板。

## 2026-07-20 MCP 实机回归

第一轮用例中，标量 IO、复杂数据绑定和 Patch 均通过；同时识别出两个边界：VM 4.4 没有已验证的数组字面量 UI 默认值编码，以及缺失的 `ShellRefrences` 被追加到参数末尾时虽可被本地解析器读取、却会被 VM 预编译器忽略。

编译器现已将 `ShellRefrences` 写入 VM 保存样本确认的规范槽位：`Output > ShellRefrences > ShellContent`。第二轮由 MCP 重新生成 Python、`System.Drawing` 和 `netDxf` 用例，用户已在 VisionMaster 4.4 实机中确认全部通过。数组端口 UI 默认值为空属于已记录的格式能力边界，确定性 Python 运行时回退已验证正常。
