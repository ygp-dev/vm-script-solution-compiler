## vm-script-tutor 同步边界

`knowledge/vm-script-tutor/` 保留 skill 原始文件，便于人工维护和追溯；`resources/vm/4.4.0/script-tutor-knowledge.json` 是编译器 Agent 的结构化消费副本，并由 `manifest.json` 记录 SHA-256。新版 Pi Agent 和旧版兼容 Agent 都会加载该 JSON。

该同步副本只增强 **2D VisionMaster C# ShellModule** 的人工脚本生成和审查知识，不把 skill 的规则扩展为新的确定性 VM API。Requirement schema、`type-system.json`、`api-catalog.json`、项目已验证样例、用户提供的 `UserProperty.cs`/`csproj`/`AlgorithmTab.xml` 和目标预编译诊断仍具有更高优先级；3D、Python、控制器 IO、UI 自动化、通信协议解析以及 VM 安装目录 DLL/EXE 反编译仍被明确排除。

资源状态中的 `vmRuntimeValidated=true` 表示 2026-07-15 用户已在 VisionMaster 4.4 中确认三类脚本正常、四个默认值可见，并且保存、关闭、重开后仍正常。
