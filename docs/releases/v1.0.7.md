# VM Script Solution Compiler 1.0.7

本版本是 1.0.6 的安装器修正版，补齐 CLI/MCP 的可见入口并增加安装后组件完整性保护。

## 修复

- 安装后开始菜单新增 CLI 和 MCP 快捷方式，避免用户误以为安装包只有 Desktop。
- 安装过程校验 `Cli\VmScriptCompiler.Cli.exe` 与 `Mcp\vm-script-compiler-mcp.exe`；缺少任一组件时中止安装并提示重新获取完整安装包。
- Desktop、CLI、MCP、Domain Worker、Agent 和安装包版本统一为 1.0.7。

## 验证

- 安装包 payload 包含 Desktop、CLI、MCP 三个产品目录。
- NSIS 安装后检查三个入口文件和开始菜单快捷方式。
- 保持 1.0.6 的知识库精简提示与按需检索行为。

下载 `VM-Script-Solution-Compiler-Setup-1.0.7-x64.exe`，按向导安装即可。默认安装到 `%LOCALAPPDATA%\\VMSC`，无需管理员权限。
