# VM Script Solution Compiler 1.0.0

首个正式 Windows x64 Release。

## 安装包内容

- Codex 风格 Desktop VM 领域 Agent；
- 固定 Node 22.19.0、Pi Agent 和自包含 Domain Worker；
- 确定性 CLI；
- 可供 Codex 等外部客户端使用的 stdio MCP；
- VM 4.4 编译资源、Requirement Schema、SOL 解析器和发布完整性清单。

## 主要能力

- Create：从自然语言 Requirement 生成纯脚本 SOL；
- Patch：在不覆盖输入文件的前提下向业务 SOL 注入脚本；
- 支持 C# ShellModule、Python PyShellModule 和全局 C#；
- 支持端口默认值、数据源绑定、外部 DLL、算子 DLL和二次开发 DLL；
- 生成结果自动执行脚本预编译、SOL parse/inspect 和离线验证；
- API Key 使用 Windows 当前用户 DPAPI 加密保存。

## 安装

下载 `VM-Script-Solution-Compiler-Setup-1.0.0-x64.exe` 并运行。安装程序不需要管理员权限，默认安装到：

```text
%LOCALAPPDATA%\VMSC
```

目标机器仍需安装 VisionMaster 4.4。安装包不包含任何 `.sol` 模板或用户方案。

安装包同时包含 Desktop、CLI 和 MCP。卸载只删除程序文件，不删除 `%LOCALAPPDATA%\VM Script Compiler` 中的用户配置、加密 API Key、对话记录，也不删除“文档”目录中的输出方案。
