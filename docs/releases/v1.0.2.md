# VM Script Solution Compiler 1.0.2

本次 Windows x64 正式版本同步发布 Desktop、CLI、MCP、Pi Agent、Domain Worker 和完整离线资源。

## 本次更新

- 新增确定性 `dxfRender` Requirement 操作，DXF 转图不再依赖模型自行编写 netDxf 源码；
- 支持 Line、Circle、Arc、Ellipse、Polyline2D/3D、Spline、Insert/Block 和 Point；
- 无可绘制实体或纯白输出时明确失败，禁止静默交付白图；
- 默认预览尺寸调整为 1920×1080，宽高可通过 VM 输入端口配置；
- 移除双重全尺寸像素缓冲，只保留最终 RGB24 缓冲和单行临时缓冲；
- Agent 增加同任务跨轮累计 6 个 Requirement 版本上限，并清理已解决的 compiler unresolved error；
- C# 预编译错误通过 CLI、MCP、Domain Worker 和 Agent 返回结构化诊断；
- Agent 工作上下文提前压缩，减少重复能力查询和长会话卡顿。

## 验证

- 项目内 `测试1.dxf` 的 20 个 Polyline2D 与 2 个 Spline 全部绘制；
- 1920×1080 RGB24 输出检测到非白像素；
- Ellipse、Insert/Block、空 DXF、结构化编译错误均有自动回归；
- Desktop、CLI、MCP、Domain Worker、Agent、Create、Patch 与发布包独立 smoke 全部通过；
- 发布包不包含 `.sol` 模板或用户方案。

下载 `VM-Script-Solution-Compiler-Setup-1.0.2-x64.exe` 运行即可。默认安装到 `%LOCALAPPDATA%\VMSC`，无需管理员权限。目标机器仍需安装 VisionMaster 4.4。

API Key、会话和用户输出不会写入发布包，卸载时也不会删除用户数据。
