# VM Script Solution Compiler 1.0.1

本次 Windows x64 正式版本同步发布 Desktop、CLI、MCP、Pi Agent、Domain Worker 和完整离线资源。

## 本次更新

- 修复 DeepSeek/OpenAI-compatible 协议选择与重复重试问题，减少生成过程中的卡顿和重复步骤；
- 优化 Desktop Agent 启动速度，支持复制对话内容和清理本地历史会话；
- 加入产品图标，并继续保持简洁的 Codex 风格桌面界面；
- 补齐 VM 4.4 全局脚本 API、初始化入口、方案路径和局部变量能力资料；
- 加强全局脚本 Requirement 约束、失败重试边界和任务名一致性校验；
- Desktop、CLI、MCP 与 Domain Worker 共享同一版确定性 Compiler Core。

## 安装包内容

- Desktop VM 领域 Agent（内置 Node 22.19.0 与 Pi Agent）；
- 自包含 Domain Worker；
- 确定性 CLI；
- 供 Codex 等外部客户端使用的 stdio MCP；
- VM 4.4 编译资源、Requirement Schema、SOL 解析器和发布完整性清单。

下载 `VM-Script-Solution-Compiler-Setup-1.0.1-x64.exe` 运行即可。默认安装到 `%LOCALAPPDATA%\VMSC`，无需管理员权限。目标机器仍需安装 VisionMaster 4.4。

安装包不包含 `.sol` 模板或用户方案。API Key、会话和用户输出不会写入发布包，卸载时也不会删除用户数据。
