# VM Script Solution Compiler 1.0.5

本版本发布 Desktop、CLI、MCP 和内置 Pi Agent 的同步 Windows x64 安装包，并同步 VM Script Tutor 知识库。

## 更新

- 同步 `knowledge/vm-script-tutor` 最新技能知识，并将结构化知识注入 Agent 提示词与旧 Agent 提示词路径。
- 增加 VM Script Tutor 资源清单、哈希校验和 smoke 测试，覆盖 `UserProperty.cs`、`AlgorithmTab.xml`、C# 5.0 兼容性与 `errorStatus` 等关键证据。
- 修正 Windows 工作区路径包含空格时的 Agent、Desktop 与 AI smoke 启动参数，确保发布回归可重复执行。
- 保持 Compiler Core、Domain Worker、MCP、Desktop、Pi Agent 和资源 manifest 使用同一版本与同步载荷。
- 发布包不包含 `.sol` 模板、用户方案或 API Key；API Key 仅保存在用户本机 DPAPI 配置中。

## 验证

- VM 4.4.0 安装探测通过：`Development`、`MVDAlgorithmSDK`、`Applications`、`GlobalScript` 均可用。
- `netDxf.dll` 2023.11.10.0 与 `MVDPositionFix.Net.dll` 已在 VM ShellModule DLL 目录验证并用于 M9/M13 回归。
- .NET 全工程 Release 构建通过，0 警告、0 错误。
- Agent 中断/继续、C#、Python、Desktop、M9 依赖、M13 DXF、社区知识、Tutor 知识和审计 smoke 通过。
- 历史专有 `docs/SOL/基础.sol` 未在本机恢复，因此依赖该文件的 M8 经典 Patch 用例未执行；该文件被仓库 `.gitignore` 排除，历史仅保留 SHA-256 证据。

下载 `VM-Script-Solution-Compiler-Setup-1.0.5-x64.exe`，按向导安装即可。默认安装到 `%LOCALAPPDATA%\\VMSC`，无需管理员权限。
