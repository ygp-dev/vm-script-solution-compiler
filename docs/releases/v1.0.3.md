# VM Script Solution Compiler 1.0.3

本次版本将最新 Desktop 字体与界面层级改造正式打包，并同步发布 Desktop、CLI、MCP、Pi Agent、Domain Worker 和完整离线资源。

## 本次更新

- UI 使用 Segoe UI Variable、Segoe UI 和 Microsoft YaHei UI 回退字体链，改善中英文混排；
- 启用 Ideal 文本排版、ClearType 和像素对齐；
- 统一标题、正文、按钮、状态和辅助信息的字号层级；
- 输入 Composer 焦点、导航选中态、消息卡片和空态使用统一的视觉反馈；
- 发布 manifest 改用并行 SHA-256 生成器，避免发布阶段重复逐文件调用 PowerShell 哈希导致长时间卡顿。
- 未确认的数组、复杂类型和输出默认值不再静默丢失；构建契约、报告及 Agent/MCP 结果会给出 `defaultPersistenceNotices`，Python 数组继续保留确定性源码回退。
- Patch 基底解析在同一构建内复用，Agent 直接使用 Core 已完成的 parse/inspect 结果，避免重复验证；取消和关闭改为非阻塞清理，并限制 Domain Worker 的输入/输出路径范围。
- Agent 默认工具流程统一为 `vm_update_requirement` → `vm_compile_solution`，校验失败会保持失败状态并返回结构化诊断。

## 验证

- Release standalone smoke：通过；
- Installer smoke：Desktop、CLI、MCP、卸载和完整性检查通过；
- 已安装 Desktop 的 UI snapshot 确认使用新字体和新布局；
- 发布包不包含 `.sol` 模板或用户方案；
- API Key 仍只保存在本机当前用户 DPAPI 加密配置中，不进入安装包。
