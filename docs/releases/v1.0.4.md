# VM Script Solution Compiler 1.0.4

本版本发布 Desktop、CLI、MCP 和内置 Pi Agent 的同步 Windows x64 安装包。

## 更新

- Agent 支持中断/继续：停止后保留 session、Requirement 状态和已有产物，可从桌面端“继续”或 RPC `continue` 恢复同一任务。
- Agent 状态新增 `runStatus` 和 `canContinue`，重启后恢复历史会话时仍能识别可继续的中断任务。
- Desktop 增加继续任务按钮，并在停止后刷新会话快照、结果索引和最近对话。
- 增加中断/继续 JSONL 冒烟测试，并纳入发布回归流程。
- 保持确定性 Compiler Core、Domain Worker、MCP 和 Desktop 使用同一版本及同一资源 manifest。
- 发布包不包含 `.sol` 模板、用户方案或 API Key；API Key 仅保存在用户本机 DPAPI 配置中。

- Agent TypeScript 类型检查通过。
- .NET 全工程 Release 构建通过，0 警告、0 错误。
- Agent 中断/继续冒烟测试通过。
