# VM Script Solution Compiler 1.0.6

本版本发布 Windows x64 Desktop、CLI、MCP 和内置 Pi Agent 安装包，并将更新后的 `vm-script-tutor` 知识整理为紧凑提示规则和按需检索知识库。

## 更新

- 版本统一升级到 1.0.6，Desktop、CLI、MCP、Domain Worker、Agent 和安装包使用同一版本号。
- 不再把完整 `vm-script-tutor` skill 原文注入 Agent 提示词；启动时只加载高置信度紧凑规则，FAQ、参考方案和选定示例通过 `vm_search_project_knowledge` 只读检索。
- 新增知识库生成、manifest 哈希同步、知识检索单元测试和发布 smoke 校验。
- 保留并集成 AS 脚本规则、角度归一化、Patch 继承、Agent 中断/继续、Desktop 搜索和窗口交互等 1.0.6 代码改动。
- 发布包不包含 `.sol` 模板、用户方案、完整 skill 原文或 API Key。

## 验证

- .NET 全解决方案 Release 构建通过：0 警告、0 错误。
- `VmScriptCompiler.Core.Tests` 通过：35/35。
- Agent TypeScript 构建通过；知识库 smoke 通过，FAQ 29 条、参考方案 14 条、tutor 选定条目 15 条，完整 skill 未进入提示词。
- 本构建机实际注册的是 VisionMaster 4.2；VisionMaster 4.4 只有本地安装包，未安装可供编译器探测的 4.4 根目录。因此依赖 VisionMaster 4.4 DLL/Python 的 Agent Create 和实机运行验证未在本机执行，发布包仍需在安装 VisionMaster 4.4 的目标机上验证。

下载 `VM-Script-Solution-Compiler-Setup-1.0.6-x64.exe`，按向导安装即可。默认安装到 `%LOCALAPPDATA%\\VMSC`，无需管理员权限。
